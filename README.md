# watch_time_updater

> [!WARNING]
> This device transmits a radio signal. Radio transmission is regulated, and the rules differ from country to country. You are responsible for checking and following the laws and regulations where you live before you build or use it.

Sets radio-controlled watches by transmitting a local JJY time signal, using time from GPS or NTP.
